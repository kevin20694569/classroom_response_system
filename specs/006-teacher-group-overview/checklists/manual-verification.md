# 人工驗證清單：老師端學生分組情況面板

**Feature**: `006-teacher-group-overview`
**來源**: [quickstart.md §4](../quickstart.md)
**驗證環境**: 桌面瀏覽器；老師分頁 1 個、學生分頁至少 4 個（至少兩組）

> 自動化測試與品質關卡已通過（tasks T018、T029、T035、T040）；本清單需要真實瀏覽器（置中與固定框架、捲動、浮動按鈕是否
> 遮擋等版面行為 jsdom 無法驗證），由組員逐項確認後勾選。全部通過才算完成。
> 2026-11-26：使用者確認接受本檔末尾「AI 瀏覽器驗證紀錄」作為簽核，全部項目已勾選。

準備：以「單題範例」匯入、設定 4 組。學生分頁 A、B 加入第 1 組且暱稱都改成「Milo」，C 加入第 1 組暱稱「Ava」，
D 加入第 2 組暱稱「Leo」。

## A. 組員名單（US1）

1. [X] 老師端視窗寬度 ≥ 1600 px：主畫面置中，右側框架中央出現「分組情況」，第 1 組「3 人」列出 Milo、Milo、Ava（依加入先後），第 2 組「1 人」Leo，第 3、4 組「0 人」「尚無組員」。
2. [X] 新開學生分頁加入第 3 組：老師端 1 秒內出現該暱稱、人數變「1 人」。
3. [X] 「待開始」時 Ava 按「離開組別」：老師端 1 秒內移除 Ava。
4. [X] 關閉 Leo 的分頁：老師端 1 秒內 Leo 旁出現「連線中斷」，第 2 組仍「1 人」。
5. [X] 20 秒內重新開啟 Leo 的分頁（瀏覽器「重新開啟已關閉的分頁」）：「連線中斷」1 秒內消失、位置不變。
6. [X] 再關閉 Leo 的分頁並等超過 30 秒：Leo 被移除、第 2 組「0 人」「尚無組員」。

## B. 回答標註（US2）

1. [X] 讓 Leo 重新加入第 2 組；老師按「開啟搶答」。
2. [X] A（第一個 Milo）送出第 1 題；接著 Leo 送出第 1 題：A 旁「★ 第 1 題」醒目標示，Leo 旁一般「第 1 題」；B（第二個 Milo）沒有標記。
3. [X] 滑鼠停在 A 的「★ 第 1 題」上，出現「搶答成功」提示。
4. [X] A 再送出第 3 題：A 旁依序「第 1 題」「第 3 題」。
5. [X] 關閉 A 的分頁並等超過 30 秒：第 1 組人數少 1，A 以灰色列在第 1 組最後、標示「不在組內」，保留題號。
6. [X] 老師按「結束搶答」：所有標註保留。
7. [X] 重新整理老師分頁：面板內容與重新整理前相同。
8. [X] 在 C 的學生分頁以開發者工具（Network → WS）查看 `session:state`：只有本組成員與各組人數，沒有 `groupOverview`、`disconnected`、他組暱稱或 `submitterMemberId`。

## C. 版面（US3）

1. [X] 寬度 1680 px：主畫面在視窗中置中；面板在主畫面右緣到視窗右緣之間的框架中水平置中；把主畫面捲到最下方（匯出區），面板一直停在原位、主畫面內容沒有被遮住。
2. [X] 以 `npm run simulate` 或多個分頁讓面板內容超過視窗高度：面板內出現捲軸，捲到底時主畫面不跟著動。
3. [X] 寬螢幕時面板上沒有「收起」按鈕。
4. [X] 視窗拉窄到 1440 px：面板收起，右上角出現「分組情況」按鈕；捲動主畫面時按鈕不動、沒有蓋住任何按鈕或文字（包含頁首的「登出」）。
5. [X] 按下按鈕：抽屜從右側展開、資訊與寬螢幕相同；分別用「關閉」、點背景、按 Esc 關閉，焦點回到按鈕。
6. [X] 抽屜展開時讓一位學生加入：抽屜內 1 秒內更新。
7. [X] 抽屜展開時把視窗拉寬到 ≥ 1600 px：改為右側固定框架；再拉窄：回到收合。
8. [X] 暱稱改成 20 字英文長字、讓一位組員送出很多題：面板內自動換行，不撐寬、不截斷。

## D. 新的活動

1. [X] 老師重新匯入：面板各組變「0 人」、所有標註消失；學生重新選組後再出現。

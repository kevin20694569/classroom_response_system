# 老師端「分組情況」面板（006）

所有文字為繁體中文（FR-020）。版面門檻：視窗寬度 1600 px（`useWideLayout`，research R6）。

## 面板內容（寬、窄兩種版面相同）

| 情況 | 顯示 |
|------|------|
| 標題 | 「分組情況」 |
| 尚未匯入（沒有組別） | 「匯入 Guided Notes 後會在這裡顯示各組組員。」 |
| 每一組 | 「第 N 組」＋「N 人」（依組別編號由小到大） |
| 該組沒有任何成員可列 | 「尚無組員」 |
| 在組內的組員 | 暱稱（依加入先後） |
| 緩衝期內斷線 | 暱稱旁文字標籤「連線中斷」 |
| 不在組內的送出者 | 排在組員之後，整列灰色，文字標籤「不在組內」 |
| 送出過的題目 | 暱稱下方膠囊「第 N 題」，依題號由小到大、自動換行 |
| 搶答成功的題目 | 膠囊醒目樣式＋「★」前綴（★ 與文字間固定間距，膠囊左右留白對稱）；`title="搶答成功"`；螢幕閱讀器讀到「第 N 題（搶答成功）」 |

可及性：寬版面的框架為 `<aside aria-label="分組情況">`（窄視窗抽屜為 `role="dialog"`），每組為
`<section aria-label="第 N 組">`，組員清單為 `<ul>`。「連線中斷」「不在組內」「搶答成功」都有文字，不只靠顏色。

## 寬版面（≥ 1600 px）

- 主畫面內容（最寬 1024 px）在視窗中水平置中（FR-011）。
- 分組情況的框架為主畫面右緣到視窗右緣之間的區域（1600 px 時寬 288 px），面板在框架內水平置中、最寬約 20rem；
  主畫面不被遮住（FR-011）。
- 面板呈浮起的卡片：圓角、細外框與向下的柔和陰影，各組卡片也有淺陰影；陰影不被框架的捲動範圍切掉。
- 框架高度等於視窗高度，固定在視窗中，不隨主畫面捲動；內容超出時框架內部捲動，捲到底不帶動主畫面（FR-013）。
- 沒有收起按鈕（FR-011）。

## 窄版面（< 1600 px）

- 面板預設收合；主畫面右側保留一欄空白，浮動按鈕「分組情況」固定在視窗右上角、位於這一欄內，捲動時位置不變，
  不蓋住主畫面的按鈕、輸入欄或文字（FR-012）。
- 按下按鈕：面板從右側展開成抽屜（寬 `min(22rem, 100vw)`），後方半透明背景；焦點移到「關閉」按鈕。
- 關閉方式：「關閉」按鈕、點背景、按 Esc；關閉後焦點回到浮動按鈕。
- 展開中資料照常即時更新（US3-6）；重新整理後回到收合。

## 版面切換（FR-014）

- 跨過 1600 px 立即切換，不需重新整理；面板資料不變。
- 窄→寬：一律顯示右側固定面板。寬→窄：回到收合。

## 不提供的操作（FR-017）

面板上沒有任何修改分組、移除組員或重新命名的按鈕。

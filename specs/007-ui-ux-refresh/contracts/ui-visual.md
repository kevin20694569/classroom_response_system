# UI 契約：共用視覺與組別識別

**Feature**: `007-ui-ux-refresh` | 對應 spec US1、US2、US5 與 FR-001～FR-011、FR-020、FR-021、FR-024～FR-027

本文件定義使用者看得到、測試可以檢查的介面約定。**所有既有文字與 `aria-label` 不變**（FR-027）；下列「新增文字」
是本子功能唯一新增的字。

## 1. 首頁（`/`，FR-005）

| 元素 | 內容 |
|------|------|
| 標題 | 「課堂搶答系統」（既有） |
| 系統說明（新增） | 「用 Guided Notes 進行分組搶答的課堂互動」 |
| 老師端入口 | 連結文字「老師端」（既有）＋圖示＋說明（新增）「匯入題目、控制搶答」，連到 `/teacher` |
| 學生端入口 | 連結文字「學生端」（既有）＋圖示＋說明（新增）「輸入暱稱、選組作答」，連到 `/student` |

入口的可存取名稱（accessible name）以「老師端」「學生端」開頭，既有以名稱尋找連結的方式仍可用。

## 2. 全站共用樣式（FR-001～FR-004、FR-006）

- 頁面背景：帶色調的淺色背景＋淡圖樣；內容卡片為白底、圓角、陰影，與背景明顯區分。
- 字型：英數字 Nunito，中文用系統繁中字型（research R4）。
- 按鈕（`apps/web/src/ui/Button.tsx`）：

  | variant | 用途 | 外觀 |
  |---------|------|------|
  | `primary` | 主要操作（確認、送出、開始搶答、匯入、匯出） | 鮮豔底色、白字、較大字級與內距 |
  | `secondary` | 次要操作（換一個、取消、修改暱稱、關閉、登出） | 白底、彩色外框與字 |
  | `danger` | 危險操作（結束搶答、離開組別、確認重新匯入） | 紅色系 |

  四種狀態：移上（變亮／上浮）、按下（下壓）、停用（降低不透明度、游標禁止）、處理中（`aria-busy="true"`＋旋轉圖示，
  不能再次按下）。原本是文字連結樣式的操作（如「修改暱稱」「離開組別」「登出」）改用按鈕樣式，文字不變。
- 鍵盤焦點：所有可操作元件有明顯的焦點外框（`focus-visible` ring，FR-024）。
- 意義圖示固定對照見 [research.md R7](../research.md#r7-意義圖示與名次標示)。

## 3. 組別識別（FR-007～FR-009a）

`GroupBadge`：組別色圓角膠囊＋白色組別圖示（`aria-hidden`）＋組別名稱「第 N 組」。

| 位置 | 呈現 |
|------|------|
| 學生端選組按鈕 | 整顆按鈕為組別色底、白字；圖示＋「第 N 組」＋「已加入：{count} 人」（既有文字）。按鈕可存取名稱仍為「第 N 組」 |
| 學生端頂端列（`PhaseBanner`） | 整條頂端列為本組顏色底、白字；左側本組圖示＋「第 N 組・暱稱」；內含白底階段標籤（§4） |
| 學生端組員名單（`GroupMemberList`） | 標題前有本組的圓形標記（`GroupBadge showName={false}`：顏色＋圖示），卡片左側有本組顏色邊條；組名由正上方頂端列顯示，不在此重複（既有測試要求同一畫面只有一處「第 N 組」文字） |
| 學生端結果畫面 | 「搶答成功：第 N 組・暱稱」前有該組的圓形標記（顏色＋圖示），文字不變；本組搶到的題目卡片左側有本組顏色邊條 |
| 老師端送出列表 | 每筆送出的組別以 `GroupBadge` 顯示（文字仍為「第 N 名・第 X 組・暱稱：」） |
| 老師端分組情況面板 | 每組標題以 `GroupBadge` 顯示 |
| 老師端結果揭曉 | 每題搶答成功組別以 `GroupBadge` 顯示 |

頁面背景不隨組別改變（FR-009a）。

## 4. 階段標示（FR-010、FR-011）

`StatusBadge`：白底膠囊，左側階段圖示、文字為既有 `SESSION_STATUS_LABEL`，文字與圖示為階段強調色，外框同色。
`data-testid="status-badge"` 不變。老師端標題旁、學生端頂端列內都使用同一元件。

## 5. 等待、空白、載入與連線（FR-020、FR-021）

| 狀態 | 位置 | 呈現（文字為既有） |
|------|------|--------------------|
| 載入中 | 學生端第一次收到資料前（整頁）；老師端第一次連上前（標題旁） | 品牌色彈跳指示＋「連線中…」；老師端維持現行「尚未連上就在標題旁顯示『連線中…』」的行為，只換成 `LoadingState` 的小尺寸樣式 |
| 尚未匯入 | 學生端選組畫面 | 插圖（FileUp 圖示組合）＋「老師尚未匯入題目，請稍候」＋漂浮動態 |
| 待開始 | 學生端作答區 | Hourglass 圖示＋「等待老師開啟搶答」＋漂浮動態 |
| 尚無送出 | 老師端送出列表 | 圖示＋「開啟搶答後，這裡會即時顯示各組送出的答案。」／「尚無組別作答」 |
| 無人搶答 | 老師端送出列表、學生端結果 | 圖示＋「無人搶答」 |
| 連線中斷（學生端，已加入組別） | 頂端列（`PhaseBanner`）內 | 文字與 `role="status"` 留在 `PhaseBanner`（既有測試單獨渲染它），改為醒目的紅底膠囊＋WifiOff 圖示：「連線中斷，正在重新連線」；頂端列本身就固定在畫面上方，不遮擋操作 |
| 連線中斷（學生端，尚未加入組別：暱稱頁、選組頁） | 畫面頂端橫幅（`ConnectionBanner`） | 此時沒有頂端列，`StudentPage` 傳 `disconnectedText="連線中斷，正在重新連線"`，曾經連上後斷線時顯示醒目橫幅（`role="status"`），不遮擋操作；加入組別後不再傳，改由頂端列顯示，同一時間畫面上只有一處中斷文字 |
| 連線中斷（老師端） | 畫面頂端橫幅（`ConnectionBanner`） | 曾經連上後斷線時，頂端固定的醒目橫幅（`role="status"`），文字為既有的「連線中…」，不遮擋操作 |
| 已重新連線（新增） | 學生端、老師端（`ConnectionBanner`） | 曾經斷線後恢復連線時，畫面頂端顯示「已重新連線」2 秒後消失；第一次連線不顯示。學生端加入組別後的 `ConnectionBanner` 不傳中斷文字，只負責這一項 |

`EmptyState` 的循環動態套用 `ui-anim`，減少動態效果時停止（FR-023）。

## 6. 版面與離線（FR-025、FR-026）

- 375～1920 px 寬度不出現水平捲動；長暱稱與長答案沿用既有 `break-words`／`whitespace-pre-wrap`。
- 006 的寬窄版面（1600 px 門檻、固定框架、浮動按鈕與抽屜）與其版面 class 不變。
- `index.html`、`index.css` 不引用任何 `http://`、`https://` 的外部資源；圖示與 Nunito 字型打包在建置結果中。

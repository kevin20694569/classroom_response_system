# UI 契約：階段變化與回饋效果

**Feature**: `007-ui-ux-refresh` | 對應 spec US3、US4 與 FR-012～FR-019、FR-023、FR-028～FR-030

所有效果只依伺服器推播的資料決定，不改變伺服器階段（FR-013）。「階段變化」的判斷規則見
[data-model.md §3](../data-model.md#3-phasetransition階段變化)：**只有分頁當場看到階段改變才出現**，首次載入、
重新整理、斷線重連後都不出現。

## 1. 切換提示（`PhaseTransitionToast`，FR-012～FR-014）

| 項目 | 約定 |
|------|------|
| 文字（新增） | READY→OPEN：「搶答開始！」；OPEN→CLOSED：「搶答結束」 |
| 位置 | 畫面上方中央，疊在內容之上 |
| 可存取性 | `role="status"`、`aria-live="polite"` |
| 操作 | 外層 `pointer-events: none`，不攔截任何點擊或輸入；沒有關閉按鈕 |
| 持續 | 1.8 秒後自動移除（≤ 2 秒） |
| 連續變化 | 新提示取代舊提示，不排隊 |
| 畫面切換 | 底下的畫面立即切換（例如結束時結果畫面立刻出現），不等提示消失 |
| 適用 | 老師端主畫面、學生端作答／結果畫面 |
| 減少動態 | 不彈跳、不淡入，直接出現與消失 |

## 2. 送出（學生端，FR-015）

- 按下送出後按鈕立即進入處理中：沿用既有文字「送出中…」與停用行為，加上 `Button` 的處理中外觀，不能重複送出。
- 成功後該題顯示送出成功標記：CircleCheck 圖示＋既有文字「已送出」／「已送出（暱稱）」，標記以 `pop-in` 動畫出現一次。
- 動畫不延後任何狀態更新：處理中外觀在按下的同一次渲染出現（FR-028）。

## 3. 搶答計時（`SessionTimer`，FR-016）

- 進行中：數字為「搶答進行中」強調色，旁邊有脈動圓點（`pulse-dot`，`ui-anim`）。
- 已結束：數字定格，改為「已結束」強調色，沒有脈動點。
- `aria-label="搶答計時"` 與既有計算方式不變。

## 4. 名次與獎盃（FR-017、FR-018）

- 老師端送出列表：第 1、2、3 名的列首顯示 Medal 圖示（金、銀、銅色）；第 4 名以後不顯示。文字「第 N 名」不變。
  既有的「搶答成功」標籤保留，改為 Trophy 圖示＋文字。
- 學生端結果畫面：每題搶答成功的答案前顯示 Trophy 圖示；只使用 `StudentView.results` 與本組 `ownSubmissions`，
  不新增任何其他組資料（FR-018）。

## 5. 新送出動態（老師端，FR-030）

- 搶答進行中，送出列表中新出現的一筆以 `slide-in`（由上方滑入＋背景短暫亮起）出現，0.9 秒結束。
- 同一次推播帶來的多筆同時出現。
- 首次載入、重新整理、重連後第一份資料中的送出直接顯示，不播放。
- 分組情況面板不加動態。

## 6. 慶祝效果（學生端，FR-019）

| 項目 | 約定 |
|------|------|
| 觸發 | 當場看到 OPEN→CLOSED，且本組至少搶到一題（`wonCount > 0`） |
| 開始 | 「搶答結束」提示消失後（1.8 秒後） |
| 持續 | 2.8 秒後移除（開始後 ≤ 3 秒） |
| 呈現 | 約 40 片組別色票顏色的紙片由上方落下，`position: fixed`、`pointer-events: none`、`aria-hidden="true"` |
| 操作 | 播放期間結果畫面可閱讀、捲動、點擊 |
| 不播放 | 本組沒搶到；首次載入、重新整理、重連後才進入結果畫面；系統設定減少動態效果 |
| 老師端 | 不播放 |

## 7. 結果揭曉（老師端，FR-029）

| 項目 | 約定 |
|------|------|
| 觸發 | 老師分頁當場看到 OPEN→CLOSED |
| 開始 | 「搶答結束」提示消失後 |
| 呈現 | `role="dialog"`、`aria-modal="true"`，標題「結果揭曉」（新增文字），蓋在主畫面上；題目多時對話框內捲動 |
| 內容 | 依題號：「第 N 題」＋搶答成功組別 `GroupBadge`＋送出者暱稱＋答案（沿用送出列表排版：題組每個子題一行「（n）答案」，長答案換行）；無人送出：「本題無人搶答」（新增文字） |
| 關閉 | 「關閉」按鈕（新增文字，開啟時取得焦點）或 Esc；關閉後回到主畫面 |
| 不出現 | 首次載入、重新整理、重連後進入「已結束」 |
| 自動關閉 | 階段不再是「已結束」，或 `activityId` 改變（另一個老師分頁重新匯入） |
| 慶祝效果 | 不播放 |
| 減少動態 | 直接出現，沒有放大或淡入 |

## 8. 減少動態效果（FR-023）

`useReducedMotion()` 讀取 `prefers-reduced-motion: reduce`（瀏覽器不支援 `matchMedia` 時視為 false），設定改變時即時更新。
CSS 端所有 `.ui-anim` 在該設定下 `animation: none`。效果的出現與消失時間點不變，只有動畫被拿掉；慶祝效果完全不渲染。

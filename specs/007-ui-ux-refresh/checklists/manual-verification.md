# 人工驗證清單：介面視覺與互動體驗改版

**Feature**: `007-ui-ux-refresh` | 依 [quickstart.md](../quickstart.md) §5

照著每一步操作，確認預期結果後勾選。

準備：老師分頁一個、學生分頁兩個（A、B），匯入課程的 Guided Notes，設定 3 組。每步「操作 → 預期結果」。

**共用風格與首頁（US1）**

- [x] 打開首頁 → 看到系統名稱、一句說明，「老師端」「學生端」兩個入口各有圖示與說明；背景不是純白，入口卡片浮在背景上
- [x] 依序看老師登入頁、老師主畫面、學生暱稱頁、選組頁 → 配色、圓角、按鈕樣式一致；主要／次要／危險按鈕外觀不同
- [x] 把滑鼠移到按鈕上、按住、在停用狀態下查看 → 三種狀態都有可見變化；用 Tab 鍵移動 → 每個按鈕與輸入欄都有明顯焦點外框

**組別識別（US2）**

- [x] 學生 A 打開選組頁 → 每組按鈕顏色與圖示都不同，仍顯示「第 N 組」與「已加入：N 人」
- [x] A 加入第 1 組、B 加入第 2 組 → A 的頂端列底色為第 1 組顏色並有第 1 組圖示，B 的為第 2 組；組員名單標題有本組徽章、卡片有本組顏色邊條；頁面背景沒有變
- [x] 老師端分組情況面板 → 第 1、2 組的顏色與圖示與學生端相同
- [x] 老師重新匯入同一份文件並設定 20 組，學生 A 重新選組 → 20 組的顏色＋圖示組合都不重複；第 1 組與第 11 組同色但圖示不同

**階段標示與切換提示（US3）**

- [x] 學生 A 在待開始 → 頂端列內的階段標籤為「待開始」強調色與圖示；作答區顯示「等待老師開啟搶答」與漂浮動態
- [x] 老師開始搶答 → 1 秒內老師端與 A、B 都出現「搶答開始！」，約 2 秒內自動消失；提示出現時 A 可以直接點輸入欄打字
- [x] 搶答進行中重新整理 A → 直接回到進行中畫面，不出現「搶答開始！」
- [x] 計時顯示 → 進行中有脈動圓點，數字為進行中顏色

**送出與名次（US4）**

- [x] A 送出第 1 題 → 按鈕立刻顯示「送出中…」且不能再按；成功後出現打勾標記與「已送出（暱稱）」
- [x] 老師端送出列表 → 新的一筆滑入並短暫亮起，約 1 秒內結束；帶有第 1 組徽章與金色獎牌「第 1 名」
- [x] B、再由另一個分頁加入第 3 組送出第 1 題 → 第 2 名銀色、第 3 名銅色；重新整理老師端 → 列表直接顯示，不播放滑入
- [x] 老師結束搶答 → A、B 的結果畫面立刻出現，「搶答結束」疊在上方約 2 秒內消失
- [x] 提示消失後 → 搶到題目的 A 出現彩色紙片落下，約 3 秒內結束；紙片落下期間可以捲動結果畫面；B 若沒搶到任何題目則沒有紙片
- [x] 老師端在提示消失後出現「結果揭曉」：每題有組別徽章、送出者暱稱與答案（題組每個子題一行），無人送出的題目顯示「本題無人搶答」；老師端沒有紙片
- [x] 按 Esc 或「關閉」 → 回到主畫面；重新整理老師端 → 不再出現結果揭曉
- [x] 重新整理 A → 結果直接顯示，沒有提示、沒有紙片

**等待、空白與連線（US5）**

- [x] 老師尚未匯入時打開新的學生分頁 → 選組畫面顯示插圖、「老師尚未匯入題目，請稍候」與漂浮動態
- [x] 搶答進行中把 A 的網路切斷（開發者工具 Network → Offline）→ A 的頂端列出現紅底的「連線中斷，正在重新連線」，仍可捲動與輸入；把老師分頁斷線 → 頂端出現「連線中…」橫幅；在選組頁（尚未加入組別）把學生分頁斷線 → 頂端出現「連線中斷，正在重新連線」橫幅
- [x] 恢復網路 → 顯示「已重新連線」約 2 秒後消失
- [x] A 斷線期間老師結束搶答，之後恢復網路 → A 直接看到結果，沒有「搶答結束」提示、沒有紙片

**減少動態、版面與離線**

- [x] 系統設定開啟「減少動態效果」（macOS：輔助使用 → 顯示器 → 減少動態；Windows：設定 → 協助工具 → 視覺效果 → 動畫效果關閉）後重跑一輪 → 提示直接出現與消失、沒有紙片、沒有漂浮與脈動、沒有滑入
- [x] 開發者工具切換寬度 375、768、1280、1920 px，檢查首頁、選組、作答、結果、老師主畫面 → 都沒有水平捲軸、文字與按鈕沒有重疊
- [x] 輸入 20 字暱稱與很長的答案 → 頂端列、組員名單、送出列表、結果揭曉都正常換行
- [x] 以 Chrome Lighthouse 的無障礙檢查（或開發者工具的對比檢查）看首頁、選組、作答、結果、老師主畫面 → 沒有對比不足的文字
- [x] 關閉電腦的網路連線後執行 `npm start` 並打開各畫面 → 圖示、字型、插圖都正常顯示

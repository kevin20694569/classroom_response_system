# 人工驗證清單：老師端介面優化

**Feature**: `002-teacher-dashboard-enhancements` | **Task**: T056 | **對應**：[quickstart.md §4](../quickstart.md)

## 使用方式

- 這份清單給開發者參考驗證步驟；完整指令與需求對應見 quickstart.md §4。
- 依序操作，每完成並確認一步就勾起來（可自己勾，或請 Claude 代為勾選）。
- 不需要記錄截圖、執行日期或執行者；有步驟不通過時，在該步下方補一行說明即可。
- 學生端以 `npm run simulate` 模擬（學生畫面於子功能 003 提供）。
- 建議另外複製一份「單題範例」「題組範例」專門給匯出測試用。

## 驗證步驟

準備：`npm start`；開老師分頁 A、B（用「開新分頁」）；另開終端機執行模擬腳本。

- [ ] 1. 分頁 A 匯入「題組範例」副本（2 組），點第 1 題 → 按鈕下方展開預覽：「題組（2 子題）」與兩個子題的標記和敘述；第 1 題按鈕標示「預覽中」
- [ ] 2. 點第 3 題 → 預覽切換為第 3 題的敘述；第 1 題按鈕回到一般狀態，只有第 3 題標示預覽中
- [ ] 3. 再點第 3 題 → 預覽收起，所有按鈕回到一般狀態
- [ ] 4. 只用鍵盤：Tab 到第 2 題按 Enter，再按一次 Enter → 第一次開啟預覽、第二次關閉
- [ ] 5. 分頁 A 預覽第 1 題時查看分頁 B → 分頁 B 沒有任何預覽
- [ ] 6. 分頁 A 預覽第 2 題後重新整理 → 回到沒有預覽的狀態
- [ ] 7. 查看活動控制段落的計時 → 顯示 `00:00.00`，不跳動
- [ ] 8. 開啟搶答 → 計時從 0 開始，小數點後兩位快速跳動
- [ ] 9. 約 20 秒後重新整理分頁 A、並看分頁 B → 兩個分頁的計時都接續約 20 秒，不從 0 開始
- [ ] 9a. 搶答進行中停止伺服器再 `npm start`，重新整理分頁 A → 計時依開啟時間接續，不從 0 開始
- [ ] 10. 預覽第 1 題，確認計時與預覽同時運作 → 預覽不影響計時與活動狀態
- [ ] 11. `npm run simulate -- --race --groups 1,2 --question 3 --answers "0"`，滑鼠移到兩筆答案後的時間圖示 → 各自浮出小視窗，顯示提交時間（到毫秒）與「開始後」時間；先送出者時間較早；小視窗不推擠版面
- [ ] 12. Tab 到時間圖示，再按 Esc／Tab 離開 → 聚焦時顯示，離開或 Esc 時關閉
- [ ] 13. 第 1 組送出第 1 題（`--group 1 --question 1 --answers "CPU" "作業系統"`），結束搶答 → 計時停止並維持不變；重新整理後仍為相同的值
- [ ] 14. 搶答結果中滑鼠移到第 1、3 題答案後的時間圖示 → 顯示搶答成功組別的提交時間；無人搶答的題目沒有時間圖示
- [ ] 15. 匯出段落查看模式選項 → 三種模式，預設「只有答案」，每種都有一句說明
- [ ] 16. 以「只有答案」匯出 → Google Sheets 結果與 001 相同；沒有組別或時間
- [ ] 17. 改以「答案＋組別時間欄」匯出 → 表頭列最右側多出「搶答組別」「提交時間」；第 1、3 題的第一列分別有組別與時間；其他題空白；作答格只有答案
- [ ] 18. 再以「答案＋組別時間欄」匯出一次 → 文件不變，沒有多出第二組欄位
- [ ] 19. 改以「答案＋格內附註行」匯出 → 第 1 題第 2 個子題格、第 3 題作答格的答案下方多一行灰色小字「〔第 N 組｜時間〕」；第 1 題第 1 個子題格只有答案
- [ ] 20. 再以「答案＋格內附註行」匯出一次 → 文件不變，附註行沒有重複
- [ ] 21. 匯出段落的「上次匯出」與完成訊息 → 顯示寫入題數與所用模式
- [ ] 22. 把剛匯出的文件重新匯入（確認放棄目前結果）→ 匯入成功，仍為 4 題、題組判斷不變
- [ ] 23. 換「單題範例」副本重跑步驟 1～3、8、13～20 → 單題的預覽與三種匯出模式皆正確
- [ ] 24. 在 Google Sheets 刪掉某個搶答成功題目的列，以任一附帶模式匯出 → 顯示無法定位的題號，文件沒有任何變更（含不會新增結果欄）
- [ ] 25. 依 [001 manual-verification.md](../../001-teacher-quiz-session/checklists/manual-verification.md) 重跑 001 的 20 個步驟 → 全部通過

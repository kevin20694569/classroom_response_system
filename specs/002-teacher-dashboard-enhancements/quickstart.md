# Quickstart：老師端介面優化

**Feature**: `002-teacher-dashboard-enhancements` | **Plan**: [plan.md](./plan.md)

## 1. 事前準備

與 001 相同：Node.js 26 LTS、Google 服務帳號金鑰、`.env`、課程兩份 Guided Notes 的副本並分享給服務帳號
（編輯者），詳見 [001 quickstart.md §1](../001-teacher-quiz-session/quickstart.md)。本子功能**不需要**新的 Google
權限或環境變數。

建議另外各複製一份「單題範例」「題組範例」專門給本子功能的匯出測試用，避免三種模式互相覆寫後難以比對。

## 2. 安裝與啟動

```bash
nvm use
```

```bash
npm ci
```

```bash
npm start
```

開啟 <http://localhost:3000/teacher>。

## 4. 人工驗證清單

準備：`npm start`；開老師分頁 A、B（用「開新分頁」）；另開終端機執行模擬腳本（用法見
[001 quickstart.md §4](../001-teacher-quiz-session/quickstart.md)）。

| # | 步驟 | 預期結果 | 需求 |
|---|------|----------|------|
| 1 | 分頁 A 匯入「題組範例」副本（2 組），點第 1 題 | 第 1 題下方展開預覽：「題組（2 子題）」與兩個子題的標記和敘述；第 1 題按鈕標示「預覽中」 | FR-001～FR-006 |
| 2 | 點第 3 題 | 預覽切換為第 3 題的敘述；第 1 題按鈕回到一般狀態，只有第 3 題標示預覽中 | FR-003、FR-005 |
| 3 | 再點第 3 題 | 預覽收起，所有按鈕回到一般狀態 | FR-004 |
| 4 | 只用鍵盤：Tab 到第 2 題按 Enter，再按一次 Enter | 第一次開啟預覽、第二次關閉 | FR-002、FR-005 |
| 5 | 分頁 A 預覽第 1 題時，查看分頁 B | 分頁 B 沒有任何預覽 | FR-007 |
| 6 | 分頁 A 預覽第 2 題後重新整理 | 回到沒有預覽的狀態 | FR-008 |
| 7 | 查看活動控制段落的計時 | 顯示 `00:00.00`，不跳動 | FR-011 |

## 5. 已知限制

- 「答案＋格內附註行」模式下，複製作答格會連附註行一起複製（模式說明中已提醒）。
- 切換匯出模式時，先前新增的「搶答組別」「提交時間」欄不會自動刪除，需要時由老師自行刪除。
- 001 留下的活動存檔沒有題目敘述；預覽會顯示「文件未提供題目敘述」，重新匯入即可取得。

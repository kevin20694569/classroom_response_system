# 人工驗證清單：使用者角色與老師端搶答活動管理

**Feature**: `001-teacher-quiz-session` | **Task**: T082 | **對應**：[quickstart.md §4](../quickstart.md)

## 使用方式

- 這份清單給開發者參考驗證步驟；完整指令、準備方式與需求對應見 quickstart.md §4。
- 依序操作，每完成並確認一步就勾起來（可自己勾，或請 Claude 代為勾選）。
- 不需要記錄截圖、執行日期或執行者；有步驟不通過時，在該步下方補一行說明即可。
- 學生端以 `npm run simulate` 模擬（學生畫面於子功能 002 提供）；002 完成後需以學生分頁重跑步驟 8～19。

## 驗證步驟

準備：`npm start`；開老師分頁 A、B（用「開新分頁」，不要用「複製分頁」）；另開終端機執行模擬腳本。

- [x] 1. 分頁 A 輸入錯誤密碼 → 顯示密碼錯誤，不透露任何密碼資訊
- [x] 2. 分頁 A 輸入正確密碼 → 進入老師端，顯示「尚未匯入」
- [x] 3. 分頁 B 不登入直接開 `/teacher` → 要求輸入密碼（身分不與分頁 A 共用）
- [x] 4. 分頁 A 匯入「題組範例」副本、組數 2 → 顯示 4 題，第 1、2 題標示題組（2 子題），狀態「待開始」
- [x] 5. 分頁 A 改匯入「單題範例」副本 → 顯示 6 題，取代先前題目
- [x] 6. 貼上非 Google Sheets 網址 → 顯示網址格式錯誤，題目不變
- [x] 7. 分頁 B 登入 → 看到與分頁 A 相同的狀態與題目
- [x] 8. 分頁 A 開啟搶答 → 分頁 A、B 在 1 秒內顯示「搶答進行中」
- [x] 9. 第 1 組送出第 1 題 → 分頁 A、B 即時出現第 1 組的答案與順位 1
- [x] 10. `--race` 讓第 1、2 組同時送出第 2 題 → 只有一組搶答成功，順位 1、2 不重複
- [x] 11. 第 2 組送出空白答案 → 腳本顯示 `ANSWER_INVALID`，老師端沒有新紀錄
- [x] 12. 重新整理分頁 A → 不需重新輸入密碼，畫面與資料不變
- [x] 13. 停止伺服器後再 `npm start`，重新整理分頁 A → 仍為「搶答進行中」，作答紀錄與順位不變
- [x] 14. 分頁 A 結束搶答 → 分頁 A、B 顯示「已結束」與每題結果，無人作答標示「無人搶答」
- [x] 15. 第 2 組再送出第 4 題 → 被拒絕（`SESSION_NOT_OPEN`）
- [x] 16. 分頁 A 嘗試再次開啟搶答 → 被拒絕，說明需重新匯入
- [x] 17. 分頁 A 匯出 → 顯示寫入題數；Google Sheets 搶答成功題目的作答格出現答案，其他儲存格不變
- [x] 18. 再匯出一次 → 文件內容與上一步相同
- [x] 19. 換用「題組範例」副本重跑步驟 4、8～14、17 → 題組作答格寫成「（1）答案」「（2）答案」
- [x] 20. 在 Google Sheets 刪掉某個搶答成功題目的列後匯出 → 顯示無法定位的題號，文件沒有任何變更

## 已完成功能與驗證對應

| User Story | 完成的功能 | 人工驗證步驟 | 自動化測試 |
|------------|------------|--------------|------------|
| US1 匯入 Guided Notes | 貼上 Google Sheets 網址匯入、依表頭與題號動態定位、單題與題組辨識、格式錯誤指出位置 | 4、5、6、19 | `guidedNotesParser`、`importQuestions`、`import` |
| US2 開啟與結束搶答 | 狀態機、全部題目同時開放、多分頁即時同步、重新整理與伺服器重啟後恢復、不可重新開啟 | 7、8、12、13、14、16 | `quizSession`、`openClose`、`sessionLifecycle`、`restart` |
| US3 檢視作答狀況與結果 | 學生加入與送出 API、伺服器順位判定、老師即時看板、結束後結果與「無人搶答」、學生看不到他組資料 | 9、10、11、14、15 | `submissions`、`concurrency`、`visibility`、`permissions` |
| US4 匯出至原 Guided Notes | 重新定位後只寫搶答成功題目的作答格、題組保留標記、可重複匯出、無法定位時不寫入 | 17、18、19、20 | `exportPlan`、`export` |
| 共通 | 老師密碼登入、分頁身分獨立、角色權限、錯誤不洩漏內部細節 | 1、2、3 | `auth`、`authService`、`tokens` |

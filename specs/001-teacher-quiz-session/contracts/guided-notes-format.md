# Guided Notes 辨識與匯出規則

**Feature**: `001-teacher-quiz-session` | 實作位置：`apps/server/src/domain/guidedNotes/`、`domain/export/`

本文件是 constitution 原則 III 要求的「定位規則文件」，也是老師準備 Guided Notes 時的使用說明依據。
規則以課程的兩份範例為基準（[spec.md](../spec.md)「Guided Notes 格式」），**不使用任何固定的儲存格座標、
列號或欄號**。系統不要求在範本加入額外的標記或佔位符。

## 1. 輸入資料

系統透過 Google Sheets API 讀取整份文件，對每個工作表取得：

- 工作表名稱
- 每個儲存格「顯示的文字」（formatted value）
- 合併儲存格範圍（merges）

**合併儲存格的值**：合併範圍內的每一格，都視為擁有合併範圍左上角那一格的值；
其「位置」也一律以左上角為準。

## 2. 找出表頭與工作表（FR-006a、FR-007）

1. 文字比對前一律去除前後空白。
2. **表頭列**：同一列中，同時有內容恰為「題號」的儲存格與內容恰為「作答」的儲存格。
   - 「題目」欄可有可無，不影響判斷；用詞不同（例如「答案」）不算表頭。
   - 題號欄 = 「題號」儲存格所在欄（合併時取左上角欄）；作答欄同理。
3. **工作表選擇**：
   - 一個工作表有且只有一列表頭 → 該工作表是「候選工作表」。
   - 同一工作表有兩列以上表頭 → 錯誤 `MULTIPLE_HEADER_ROWS`。
   - 全部工作表中恰有 1 張候選 → 使用它；0 張 → `HEADER_NOT_FOUND`；2 張以上 → `MULTIPLE_GUIDED_NOTES_SHEETS`
     （訊息列出相關工作表名稱）。
   - 不依工作表名稱、順序或網址中的分頁編號判斷。

## 3. 辨識題號（FR-007a）

對表頭以下的每一列，取題號欄的值（依第 1 節處理合併），去除前後空白後：

| 內容 | 結果 |
|------|------|
| 空白 | 這一列不屬於任何題目（題目之間的分隔列） |
| `1`、`1.`、`1、`、`Q1`／`q1`、`第1題`；數字可為半形或全形（`１`） | 題號 1 |
| 其他任何內容（例如 `A-1`、`一`、`備註`） | 錯誤 `INVALID_QUESTION_NUMBER`（指出工作表與列） |

- 題號必須是正整數（`0` 視為錯誤）。

## 4. 組成題目（單題與題組，FR-009a）

1. 由上而下掃描，**連續且題號相同**的列組成一個「題目區塊」。題號相同的來源可以是
   (a) 同一個合併儲存格跨越多列，或 (b) 相鄰的列各自寫上相同題號。空白分隔列會結束目前區塊。
2. 若同一題號在不相鄰的兩個區塊出現 → 錯誤 `DUPLICATE_QUESTION_NUMBER`（列出兩處位置）。
3. **作答格**：區塊內每一列在作答欄的儲存格，依第 1 節合併規則取左上角位置後去除重複，
   依列由上而下排列，得到 1 個或多個作答格。
   - 1 個作答格 → `single`（單題）。例：單題範例每題的作答格是跨兩列的合併儲存格，只算 1 個。
   - 2 個以上 → `group`（題組），子題序號依序為 1、2、3…
4. 文件中沒有任何題目 → 錯誤 `NO_QUESTIONS`。

## 5. 子題標記

- 標記格式：作答格文字開頭為 `（n）` 或 `(n)`（全形或半形括號，`n` 為半形或全形數字，括號內可有空白）。
- 匯入時作答格的其他文字一律忽略（可能是佔位符或舊答案）。
- 題組的標記規則：
  - 全部子題都沒有標記 → 允許。
  - 全部子題都有標記，且數字依序等於 1、2、3… → 允許；標記原文保存為 `Blank.label`。
  - 只有部分子題有標記 → 錯誤 `PARTIAL_BLANK_MARKERS`。
  - 標記數字不連續或不是從 1 開始 → 錯誤 `INVALID_BLANK_MARKERS`。
- 單題的作答格即使以標記開頭，也只當作一般文字（單題沒有子題標記）。

## 6. 驗證與錯誤回報（FR-010）

- 解析會**收集所有錯誤**後一次回報，而不是遇到第一個就停止，方便老師一次修正。
- 每個錯誤包含 `code`、繁體中文訊息，以及能取得的位置：工作表名稱、列號（1 起，與試算表畫面一致）、
  欄名（例如 `G`）、題號。
- 有任何錯誤時，整次匯入失敗，系統資料不變。

| 錯誤代碼 | 說明 |
|----------|------|
| `HEADER_NOT_FOUND` | 找不到同時含「題號」與「作答」的表頭列 |
| `MULTIPLE_HEADER_ROWS` | 同一工作表有多列表頭 |
| `MULTIPLE_GUIDED_NOTES_SHEETS` | 超過一張工作表含表頭 |
| `INVALID_QUESTION_NUMBER` | 題號欄內容無法辨識為題號 |
| `DUPLICATE_QUESTION_NUMBER` | 同一題號出現在不相鄰的位置 |
| `NO_QUESTIONS` | 表頭以下沒有任何題目 |
| `PARTIAL_BLANK_MARKERS` | 題組只有部分子題有「（n）」標記 |
| `INVALID_BLANK_MARKERS` | 題組標記不是從（1）開始連號 |

## 7. 匯出規則（FR-021～FR-024）

1. 重新讀取整份文件，依第 2～5 節**重新解析並定位**（不使用匯入時保存的位置）。
2. 對每個有搶答成功組別的題目，依題號找到新解析結果中的同一題：
   - 找不到該題號，或子題數與匯入時不同 → 記為無法定位。
3. 有任何無法定位的題目 → 回傳 `EXPORT_LOCATE_FAILED`（列出題號），**不寫入任何儲存格**。
4. 全部可定位時，計算每個作答格要寫入的文字：
   - 單題：`答案`
   - 題組子題：該格目前有標記 → `標記原文 + 答案`（例如 `（1）CPU`）；沒有標記 → `答案`
5. 以一次批次請求寫入，`valueInputOption = RAW`（答案以純文字寫入，不會被當成公式）。
6. 只寫入上述作答格；無人搶答的題目、文件其他儲存格一律不動。既有內容直接覆寫。
7. 重複匯出會得到相同結果：第二次匯出時，子題格以 `（1）CPU` 開頭，標記仍被辨識為 `（1）`，
   寫入內容不變。

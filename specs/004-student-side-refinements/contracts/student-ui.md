# 學生端畫面（004）

只列出相對 003 新增或改變的畫面與文字；其餘沿用 [003 student-ui.md](../../003-student-quiz-participation/contracts/student-ui.md)。

## 1. 暱稱頁（`/student`，分頁還沒有暱稱時）

- 標題：「輸入你的暱稱」
- 說明：「暱稱會顯示給同組同學與老師。」
- 輸入欄（標籤「暱稱」）：預填 `randomNickname()`；輸入時顯示字數「N / 20」。
- 按鈕：「換一個」（以另一個隨機名字取代輸入欄）、「確認」（主要按鈕；按 Enter 等同確認）。
- 錯誤（輸入欄下方）：「暱稱需為 1～20 字，且不能只有空白。」
- 修改暱稱進入時：輸入欄顯示目前暱稱，另有「取消」回到選組畫面。
- 老師身分分頁不顯示此頁（沿用 003 FR-008）。

## 2. 選組畫面（修改）

- 上方：「暱稱：Milo」與連結按鈕「修改暱稱」。
- 每個組別按鈕：「第 N 組」，下方小字「已加入：K 人」（K 為 0 也顯示）。
- 老師尚未匯入：沿用「老師尚未匯入題目，請稍候」，上方仍顯示暱稱。
- 身分失效說明沿用 003。

## 3. 組別頂端列與成員名單（修改／新增）

- 頂端列：「第 2 組・Milo」＋階段標籤＋連線狀態（沿用 003），READY 時有「離開組別」。
- 離開失敗時顯示：「離開組別失敗，請確認連線後再試一次。」或伺服器訊息。
- 成員名單（作答與結果畫面都顯示，放在頂端列下方）：
  - 標題「本組成員（K 人）」
  - 依加入先後列出暱稱；自己的暱稱後加「（你）」；暱稱相同時都列出。
  - 人數多時換行排列，不截斷。

## 4. 題目（作答畫面，修改）

- READY：與 003 相同，只有題號、題型與子題標記，輸入欄停用，提示「等待老師開啟搶答」。
- OPEN：每題以 `QuestionContent` 呈現（與老師端預覽相同）：「第 N 題」＋題型（「單題」或「題組（K 子題）」）、
  題目敘述（保留換行、不截斷）；題組每個子題顯示標記與子題敘述，下一行為該子題的輸入欄。
  - 沒有敘述：灰色「文件未提供題目敘述」。
- 已送出：敘述照常顯示，輸入欄換成唯讀答案，狀態為「已送出（Milo）」；送出者為 null 時顯示「已送出」。

## 5. 結果畫面（修改）

- 每題顯示 `QuestionContent`（題目敘述），下方為結果：
  - 搶答成功答案旁顯示「第 1 組・Milo」（送出者為 null 時只顯示組別）。
  - 本組「已送出，未搶到」：本組答案標「本組（Leo）」，搶答成功答案標「第 1 組・Milo」。
  - 「無人搶答」沿用 003。

## 5a. 搶答計時（converge 新增）

- 「已送出（暱稱）」標籤在有題目敘述時放在題目與答案下方。

- 頂端列顯示「搶答計時」，格式與老師端相同（mm:ss.cc），計算方式與老師端共用。

## 6. 老師端（修改）

- 送出列表每筆加上送出者：「第 2 組・Milo」；送出者為 null 時只顯示組別。
- 送出列表版面（FR-037）：第一行「第 N 名・第 X 組・Milo：」＋提交時間圖示＋（第一名）「搶答成功」；下面每個子題一行
  「（n）答案」，單題一行答案；長答案自動換行。
- 老師端不顯示各組人數與成員名單。

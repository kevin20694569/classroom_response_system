# Quickstart：學生端細修：暱稱、組別人數與題目敘述

**Feature**: `004-student-side-refinements` | **Plan**: [plan.md](./plan.md)

## 1. 事前準備

與 001 相同：Node.js 26 LTS、Google 服務帳號金鑰、`.env`、課程兩份 Guided Notes 的副本並分享給服務帳號，
詳見 [001 quickstart.md §1](../001-teacher-quiz-session/quickstart.md)。本子功能**不需要**新的 Google 權限
或環境變數；新增的 web 相依套件由 `npm ci` 安裝。

## 2. 安裝與啟動

```bash
nvm use
```

```bash
npm ci
```

```bash
npm start
```

首頁：<http://localhost:3000/>；老師端：`/teacher`；學生端：`/student`。

## 4. 人工驗證清單

準備：用新的暫存資料夾啟動，才會是「老師尚未匯入」：`DATA_DIR=<新資料夾的路徑> npm start`（不要用專案的 `data/`）。
整份驗證都用同一個資料夾。開老師分頁 T（登入）；學生分頁 A、B、C、D 都用「開新分頁」開啟（不要用「複製分頁」）。

1. 分頁 A 從首頁按「學生端」 → 顯示暱稱頁，說明為「暱稱會顯示給同組同學與老師。」，輸入欄已有一個英文短名字
2. 分頁 A 連按「換一個」數次 → 每次都換成不同的英文名字
3. 分頁 A 把暱稱清空後按確認 → 不前進，顯示暱稱規則；輸入 21 個字也一樣
4. 分頁 A 改成「小明」並確認 → 進入選組畫面，顯示「暱稱：小明」與「老師尚未匯入題目，請稍候」
5. 分頁 A 重新整理 → 暱稱仍是「小明」，不需重新輸入
6. 分頁 B 直接打開 `/student` 網址 → 也先顯示暱稱頁；以預設名字確認
7. 分頁 T 匯入「題組範例」副本（3 組） → 分頁 A、B 不需重新整理就出現三個組別，每組「已加入：0 人」
8. 分頁 A 選第 1 組 → 分頁 B 的第 1 組在 1 秒內變成「已加入：1 人」；分頁 A 顯示「本組成員（1 人）」與「小明（你）」；頂端列的搶答計時為 00:00.00
9. 分頁 B 選第 1 組；分頁 C 以暱稱「小明」加入第 1 組 → 三個分頁的成員名單都有 3 人，兩個「小明」都列出
10. 分頁 D 確認暱稱後停在選組畫面 → 第 1 組「已加入：3 人」，看不到任何成員名字
11. 分頁 A 連續重新整理 3 次 → 其他分頁的人數一直是 3，沒有短暫變少或變多
12. 分頁 C 在組內時畫面沒有「修改暱稱」；分頁 C 按「離開組別」 → 第 1 組在 1 秒內變成 2 人；分頁 C 回到選組畫面，暱稱保留，按「修改暱稱」改成「Leo」後加入第 2 組
13. 關閉分頁 B → 30 秒內第 1 組人數與名冊移除分頁 B 的暱稱
14. 「待開始」時分頁 A 的題目只有題號與子題標記，沒有題目敘述
15. 分頁 T 開啟搶答 → 分頁 A、C 的每一題都顯示題目敘述，題組每個子題旁有子題敘述與輸入欄；文字與分頁 T 的題目預覽相同；分頁 D（未選組）看不到敘述；分頁 A、C 的搶答計時與分頁 T 同步走動（相差不超過 1 秒）
16. 分頁 C 先送出第 1 題（故意填錯），分頁 A 再送出第 1 題（填對） → 分頁 A 同組顯示「已送出（小明）」；分頁 T 的送出列表依序顯示「第 2 組・Leo」「第 1 組・小明」；分頁 A 看不到 Leo、分頁 C 看不到小明
17. 搶答進行中，分頁 A、C 都沒有「離開組別」
18. 分頁 T 結束搶答 → 學生分頁的計時停在與分頁 T 相同的總時間；分頁 A、C 第 1 題都顯示「等待老師批改」，看不到其他組的答案；分頁 T 每筆送出前有勾選框，旁邊有使用提示與「批改完成」按鈕
19. 分頁 T 勾選第 1 組第 1 題 → 分頁 A 在 1 秒內顯示「答對」；取消勾選後回到「等待老師批改」；再勾選一次
20. 分頁 T 按「批改完成」 → 分頁 C 第 1 題顯示「答錯」，分頁 A 顯示「本組搶答成功」；所有學生分頁第 1 題顯示「搶答成功：第 1 組・小明」；沒有任何勾選的題目顯示「無人答對」；成員名單仍顯示
21. 分頁 T 再勾選第 2 組第 1 題 → 分頁 C 第 1 題在 1 秒內變成「回答成功」（第 1 組較早送出，仍為搶答成功）
22. 分頁 T 以「答案＋格內附註行」匯出 → 文件第 1 題寫入第 1 組的答案，附註行為「〔第 1 組｜小明｜時間〕」；沒有勾選答對的題目沒有寫入
23. 分頁 T 以「答案＋組別時間欄」匯出 → 表頭多一欄「搶答送出者」，第 1 題該欄為「小明」；沒有答對的題目結果欄為空；再匯出一次內容相同、沒有多出新欄
24. 以「單題範例」副本重複步驟 7～23 的主要流程（匯入、加入、作答、結束、批改、匯出） → 結果一致
25. 關閉伺服器（Ctrl+C）後用同一個 `DATA_DIR` 再 `npm start`，不重新整理任何分頁 → 學生分頁自動重連，成員名單、人數、批改結果在幾秒內恢復，暱稱不需重新輸入
26. 分頁 T 重新匯入（確認放棄結果） → 所有學生分頁回到選組畫面並說明原因，暱稱保留，各組「已加入：0 人」
27. 分頁 T 開 `/student` → 顯示老師身分提示，沒有暱稱頁與作答功能
28. 重跑 003 人工驗證中與本次改動相關的步驟（作答、送出、結果；結果改依批改），全部通過

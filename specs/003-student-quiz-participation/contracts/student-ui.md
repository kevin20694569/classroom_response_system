# 學生端畫面契約

**Feature**: `003-student-quiz-participation` | 需求：[spec.md](../spec.md) | 元件：[component 圖](../../../diagrams/003-student-quiz-participation-component.puml)

學生端路徑為 `/student`。本文件規定各畫面要顯示的內容與文字，作為元件測試與人工驗證的依據；所有文字使用
繁體中文，不顯示堆疊、檔案路徑或憑證（FR-027）。

## 1. 畫面與顯示條件

| 畫面 | 條件 | 內容 |
|------|------|------|
| 等待匯入 | 沒有 token，`view.status === 'NOT_IMPORTED'` | 「老師尚未匯入題目，請稍候」；沒有組別選項 |
| 選擇組別 | 沒有 token，`view.status` 不是 `NOT_IMPORTED` | 「第 1 組」～「第 N 組」按鈕；有失效原因時在上方顯示（research R4） |
| 老師身分提示 | 有 token，`view.viewer === 'teacher'` | 「這個分頁目前是老師身分，請另開新分頁以學生身分加入」；沒有選組與作答功能 |
| 待開始 | `StudentView.status === 'READY'` | 頂端列 + 題目清單（輸入停用）+「等待老師開啟搶答」 |
| 搶答進行中 | `StudentView.status === 'OPEN'` | 頂端列 + 題號清單 + 所有題目的作答表單 |
| 已結束 | `StudentView.status === 'CLOSED'` | 頂端列 + 結果畫面 |
| 載入中 | 尚未收到第一個 `session:state` | 「連線中…」 |

## 2. 頂端列（PhaseBanner）

- 一直顯示「第 N 組」與活動階段（待開始／搶答進行中／已結束），FR-004、FR-009。
- 斷線時顯示「連線中斷，正在重新連線」（FR-010）。
- 只有「待開始」顯示「離開組別」按鈕（FR-005、Clarifications Q2）。

## 3. 作答畫面（AnswerSheet、QuestionAnswerForm）

- 題號清單：每題一個按鈕，顯示「第 n 題」與本組狀態「未作答」或「已送出」；點擊後捲到該題並聚焦第一個
  輸入欄（FR-012、FR-013）。
- 每題一個區塊，由上到下依題號排列：
  - 標題「第 n 題」與「單題」或「題組（k 子題）」。
  - 單題：一個輸入欄；題組：每個子題一個輸入欄，前面標示子題標記（research R5）。
  - 每個輸入欄下方顯示字數「m／200」（FR-014）。
  - 「送出」按鈕；處理中顯示「送出中…」且停用（FR-019）。
  - 已送出：標示「已送出」，以唯讀文字顯示本組答案，沒有輸入欄與送出按鈕（FR-015）。
- 送出成功訊息：「已送出」；不顯示順位或是否搶答成功（FR-016）。
- 前端檢查訊息（在對應子題下方）：「尚未填寫」「超過 200 字」（FR-014）。
- 搶答結束時若仍有未送出的內容：「搶答已結束，尚未送出的答案不會被採計」（FR-018）。
- 送出失敗訊息見 [http-api.md §3](./http-api.md)。

## 4. 結果畫面（StudentResultBoard）

- 上方：「本組搶答成功 N 題」（FR-025）。
- 依題號列出每題：
  - 搶答成功組別與答案（題組依子題分列，每列前有子題標記）；無人搶答顯示「無人搶答」（FR-024）。
  - 本組成績標籤：「本組搶答成功」「已送出，未搶到」「本組未作答」；「已送出，未搶到」時另外列出本組答案
    （FR-025）。
- 不顯示其他組別未搶到的答案、送出順序或時間（Clarifications Q1）。

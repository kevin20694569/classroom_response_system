# 人工驗證清單：學生端搶答作答與結果檢視

**Feature**: `003-student-quiz-participation` | **Task**: T040 | **對應**：[quickstart.md §4](../quickstart.md)

## 使用方式

- 依序操作，每完成並確認一步就勾起來（可自己勾，或請 Claude 代為勾選）。
- 不需要記錄截圖、執行日期或執行者；有步驟不通過時，在該步下方補一行說明即可。
- 需求對應與準備方式見 quickstart.md §4。

## 驗證步驟

準備：`npm start`；開老師分頁 T（登入）；用「開新分頁」開學生分頁 A、B、C（不要用「複製分頁」）。

- [ ] 1. 老師尚未匯入時，分頁 A 開 `/student` → 顯示「老師尚未匯入題目，請稍候」，沒有組別選項
- [ ] 2. 分頁 T 匯入「題組範例」副本（3 組） → 分頁 A 不需重新整理就出現「第 1 組」～「第 3 組」
- [ ] 3. 分頁 A 選第 1 組、分頁 B 選第 2 組、分頁 C 選第 2 組 → 各分頁顯示自己的組別與「待開始」；題目清單的輸入欄停用，提示「等待老師開啟搶答」；有「離開組別」按鈕
- [ ] 4. 分頁 C 按「離開組別」，改選第 2 組 → 回到選組畫面，重新加入第 2 組
- [ ] 5. 分頁 T 開 `/student` → 顯示這是老師身分的提示，沒有作答功能；回到 `/teacher` 仍是登入狀態
- [ ] 6. 分頁 T 開啟搶答 → 分頁 A、B、C 在 1 秒內變為「搶答進行中」；所有題目一次列出、可輸入；「離開組別」消失
- [ ] 7. 分頁 A 點題號清單的第 3 題 → 捲到第 3 題並聚焦輸入欄
- [ ] 8. 分頁 A 第 1 題只填（1）就送出 → 不送出，（2）下方顯示「尚未填寫」
- [ ] 9. 分頁 A 第 3 題輸入只有空白、再輸入超過 200 字 → 都不送出並指出原因；字數顯示正確
- [ ] 10. 分頁 A 第 1 題（1）（2）打一半後重新整理 → 仍是第 1 組、搶答進行中，打過的內容還在
- [ ] 11. 分頁 A 送出第 1 題 → 顯示「已送出」與本組答案、輸入欄消失；沒有順位或是否搶答成功；分頁 T 即時看到第 1 組答案；分頁 B、C 沒有任何變化
- [ ] 12. 分頁 B 送出第 3 題 → 分頁 C 在 1 秒內也顯示第 3 題「已送出」與第 2 組答案
- [ ] 13. 分頁 B、C 都在第 2 題填好，幾乎同時按送出 → 只有一筆被採計；另一個分頁顯示「本組已送出此題」與採計的答案
- [ ] 14. 分頁 C 在第 4 題輸入內容但不送出；停止伺服器 → 分頁 A、B、C 顯示「連線中斷，正在重新連線」，送出按鈕停用
- [ ] 15. 再 `npm start` → 各分頁自動恢復：組別、階段、本組已送出內容正確；分頁 C 第 4 題的輸入還在
- [ ] 16. 分頁 A 第 1 題已送出後，在第 2 題輸入內容，分頁 T 結束搶答 → 所有學生分頁 1 秒內切到結果；分頁 A 說明尚未送出的答案不會被採計
- [ ] 17. 查看分頁 A 的結果 → 第 1 題「本組搶答成功」；第 2、3 題顯示第 2 組的答案並標示「本組未作答」；第 4 題「無人搶答」；上方「本組搶答成功 1 題」
- [ ] 18. 查看分頁 B 的結果 → 第 2、3 題「本組搶答成功」；第 1 題「本組未作答」；上方「本組搶答成功 2 題」；看不到其他組未搶到的答案；與分頁 T 的搶答成功組別與答案一致
- [ ] 19. 結束後讓模擬腳本以第 3 組送出第 4 題（`npm run simulate`，用法見 001 quickstart §4） → 被拒絕（`SESSION_NOT_OPEN`），結果不變
- [ ] 20. 重新整理分頁 B → 仍顯示相同結果；沒有「離開組別」
- [ ] 21. 分頁 T 重新匯入「單題範例」（確認放棄目前結果） → 分頁 A、B、C 回到選組畫面並顯示「老師已開始新的活動，請重新選擇組別」
- [ ] 22. 用「單題範例」以兩組學生分頁重跑步驟 3、6、11、16～18 → 單題只有一個輸入欄、沒有子題標記；整個流程 5 分鐘內完成
- [ ] 23. 依 [001 manual-verification.md](../001-teacher-quiz-session/checklists/manual-verification.md) 重跑 001 步驟 8～19，學生的動作改用學生分頁（`--race` 改為兩個學生分頁同時送出，空白答案改在學生分頁輸入並確認畫面擋下） → 全部通過

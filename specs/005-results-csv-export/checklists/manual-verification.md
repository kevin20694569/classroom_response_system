# 人工驗證清單：搶答結果匯出 CSV

**Feature**: `005-results-csv-export`
**來源**: [quickstart.md §5](../quickstart.md)
**驗證環境**: Windows 版 Excel（SC-003 只驗 Windows；macOS 由自動化的編碼記號測試涵蓋）

> 自動化測試與品質關卡已通過；本清單的項目需要真實瀏覽器與 Excel，由人工逐項確認後勾選。
> 全部通過才算完成（T043）。額外確認：從按下「匯出 CSV」到瀏覽器存下檔案在 3 秒內（SC-001）。

### A. 單題範例（老師＋第 1、2 組各一個分頁，設定 3 組）

1. [X] 老師匯入「單題範例」。「匯出 CSV」按鈕停用，旁邊顯示「搶答結束後才能匯出 CSV。」
2. [X] 開啟搶答。按鈕仍然停用、提示仍在。
3. [X] 第 2 組（暱稱 Milo）送出第 1 題答案「蘋果, 香蕉」；第 1 組（暱稱 `A,B`）接著送出第 1 題，答案「橘子」。
   （學生端輸入欄是單行，無法輸入換行；答案含換行的情況由自動化測試以 API 直接送出驗證。）
4. [X] 第 1 組送出第 2 題答案「=1+1」；第 2 組送出第 3 題答案 `他說"好"`。其餘題目都不作答。
5. [X] 老師結束搶答。1 秒內「匯出 CSV」變成可以按，提示消失；不需重新整理。
6. [X] 按下「匯出 CSV」，從按下到瀏覽器存下檔案在 3 秒內（SC-001）。瀏覽器下載「搶答結果_YYYYMMDD-HHmm.csv」，時間與開啟搶答的時間相同；畫面顯示「已下載 …」。
7. [X] 在檔案總管對檔案點兩下，用 Windows 版 Excel 直接開啟：表頭與所有中文正常，沒有亂碼。
8. [X] 表頭依序為「題號、子題、組別、送出者暱稱、答案、搶答順位、送出時間、是否搶答成功」；單題的「子題」欄都是空的。
9. [X] 第 1 題有兩列：第 2 組 Milo「蘋果, 香蕉」第 1 名、是；第 1 組 `A,B`（完整在送出者暱稱欄）「橘子」、第 2 名、否。後面的欄位都沒有錯位。
10. [X] 第 2 題答案顯示為文字「=1+1」（開頭可能多一個 `'`），沒有被算成 2；第 3 題顯示 `他說"好"`。
11. [X] 答案或暱稱為「007」「1/2」「3:30」「TRUE」這類值時，Excel 顯示原樣（007 沒變 7、1/2 沒變日期或分數、TRUE 沒變布林），儲存格內容不多出單引號。
12. [X] 「送出時間」欄在 Excel 直接顯示完整的日期與時間（如「2026-11-26 13:11:00」），不是「分:秒.小數」；欄寬不足時顯示 `####` 屬正常，拉寬即可。
13. [X] 每一題沒有人作答的題目都恰好一列，答案為「無人作答」，其他欄位空白；所有列依題號、再依順位排序。
14. [X] 與老師端送出列表逐筆比對：組別、送出者、答案、「第 N 名」與搶答成功標示完全一致（SC-002）。
15. [X] 再按一次「匯出 CSV」，下載的檔名相同；用比較工具（例如 `fc /b`）比對兩份檔案，內容完全相同。
16. [X] 以學生分頁的開發者工具確認：學生端沒有「匯出 CSV」按鈕，學生收到的資料沒有任何 CSV 內容。

### B. 題組範例（老師＋第 1、2 組各兩個分頁，設定 4 組）

1. [X] 老師匯入「題組範例」並開啟搶答。
2. [X] 第 3 組送出第 1 題（題組），接著第 1 組也送出第 1 題；某一題完全不作答；第 4 組送出另一題。
3. [X] 結束搶答並匯出 CSV，用 Excel 開啟。
4. [X] 第 1 題第 3 組的送出拆成每個子題一列，「子題」欄依序為「子題1」「子題2」（不是「（1）」，也不是 -1、-2 或日期），各列的組別、送出者、
       順位、時間、是否搶答成功都相同；第 3 組的所有子題列都排在第 1 組之前。
5. [X] 無人作答的題組只有一列「無人作答」，「子題」欄空白。

### C. 錯誤處理與既有功能

1. [X] 在結束搶答後重新整理老師分頁，「匯出 CSV」仍可使用。
2. [X] 結束搶答後停止伺服器（Ctrl+C）再 `npm start`，重新登入老師端後匯出，內容與重新啟動前相同。
3. [X] 停止伺服器後在老師端按「匯出 CSV」：顯示「無法連線到伺服器，請確認系統已啟動。」，沒有下載任何檔案。
4. [X] 以三種模式各執行一次「匯出至原 Guided Notes」，結果與 004 相同（附註行、送出者欄位、只寫入搶答成功答案）；
       匯出 CSV 不會改變「上次匯出」的資訊，也不會修改 Guided Notes 文件。
5. [X] 檢查伺服器 log：每次 CSV 匯出都有一筆 `csv_export.succeeded`（或 `csv_export.failed`）紀錄，只含列數或錯誤代碼，
       不含答案或暱稱。

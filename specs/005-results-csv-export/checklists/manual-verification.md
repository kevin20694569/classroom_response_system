### A. 單題範例（老師＋第 1、2 組各一個分頁，設定 3 組）

1. [X] 老師匯入「單題範例」。「匯出 CSV」按鈕停用，旁邊顯示「搶答結束後才能匯出 CSV。」

3. [X] 第 2 組（暱稱 Milo）送出第 1 題答案「蘋果, 香蕉」；第 1 組（暱稱 `A,B`）接著送出第 1 題，答案「橘子」。
   （學生端輸入欄是單行，無法輸入換行；答案含換行的情況由自動化測試以 API 直接送出驗證。）
   - 🤖 AI 自動驗證（2026-11-26，非人工）：通過（資料面）。以 API 加入並送出：Milo 先送、`A,B` 後送，伺服器排名為第 1 名、第 2 名。學生分頁的實際輸入畫面未涵蓋，由人工補看。
4. [X] 第 1 組送出第 2 題答案「=1+1」；第 2 組送出第 3 題答案 `他說"好"`。其餘題目都不作答。
   - 🤖 AI 自動驗證（2026-11-26，非人工）：通過（資料面）。以 API 送出「=1+1」與 `他說"好"`，第 4～6 題維持無人作答。
5. [X] 老師結束搶答。1 秒內「匯出 CSV」變成可以按，提示消失；不需重新整理。
   - 🤖 AI 自動驗證（2026-11-26，非人工）：部分通過。結束搶答 API 回 200，結束後匯出由 409 變 200。「1 秒內按鈕變可按、提示消失」是畫面行為，需人工確認。

## 仍需人工確認的精簡步驟

只剩 Excel、瀏覽器與 Google 文件的目視確認。同一場完成：

1. `npm start`，老師匯入「單題範例」、3 組並開啟搶答；第 1、2 組各開一個學生分頁。
2. 在學生分頁實際輸入並送出：第 2 組 Milo「蘋果, 香蕉」，第 1 組 `A,B`「橘子」，第 1 組第 2 題「=1+1」，第 2 組第 3 題 `他說"好"`。看到送出成功。 `[A.3、A.4]`

5. 按「匯出 CSV」：3 秒內瀏覽器存下「搶答結果_…csv」，畫面顯示「已下載 …」。 `[A.6]`
6. 用 Excel 開啟：「=1+1」顯示為文字，不是 2；`他說"好"` 原樣顯示。 `[A.10]`

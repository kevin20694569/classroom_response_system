# CSV 檔案格式契約

**Feature**: `005-results-csv-export`

## 1. 編碼與結構

| 項目 | 規定 | 依據 |
|------|------|------|
| 字元編碼 | UTF-8，檔案開頭為 BOM（位元組 `EF BB BF`） | FR-011、research R4 |
| 換列 | CRLF（`\r\n`），最後一列之後也有 CRLF | RFC 4180 |
| 分隔字元 | 逗號 `,` | FR-012 |
| 欄數 | 每列固定 8 欄 | FR-005 |
| 第一列 | 表頭：`題號,子題,組別,送出者暱稱,答案,搶答順位,送出時間,是否搶答成功` | FR-005 |

## 2. 欄位值的編碼規則（依序套用）

1. **公式防護**（FR-013）：值的第一個字元是 `=`、`+`、`-`、`@`、Tab（`\t`）或 CR（`\r`）時，在開頭加上 `'`。
2. **引號**（FR-012）：值含有 `,`、`"`、`\r`、`\n`，或開頭／結尾是空白時，整個值用 `"` 包住，值中的每個 `"` 寫成 `""`。
3. 其他值原樣輸出；空值（`null`）輸出空字串。

| 原始值 | 輸出 |
|--------|------|
| `甲` | `甲` |
| `蘋果, 香蕉` | `"蘋果, 香蕉"` |
| `他說"好"` | `"他說""好"""` |
| `第一行⏎第二行`（LF） | `"第一行⏎第二行"` |
| `=1+1` | `'=1+1` |
| `-5` | `'-5` |
| `=SUM(A1, B1)` | `"'=SUM(A1, B1)"` |
| ` 前後空白 ` | `" 前後空白 "` |
| `A,B`（暱稱） | `"A,B"` |
| `null` | （空） |

## 3. 列的內容與排序

欄位定義見 [data-model.md §2 ResultRow](../data-model.md)。排序：題號由小到大 → 同題依順位 → 同一筆題組送出依子題順序。

## 4. 範例

活動：第 1 題為 2 個子題的題組（子題標記「（1）」「（2）」），第 2 題單題無人作答，第 3 題單題；
第 3 組 Milo 先送出第 1 題，第 1 組 Ava 接著送出；004 之前保存的第 2 組送出（沒有暱稱）送出第 3 題，答案含逗號。

```text
﻿題號,子題,組別,送出者暱稱,答案,搶答順位,送出時間,是否搶答成功
1,（1）,第 3 組,Milo,甲,第 1 名,2026/11/26 10:32:15.123,是
1,（2）,第 3 組,Milo,乙,第 1 名,2026/11/26 10:32:15.123,是
1,（1）,第 1 組,Ava,丙,第 2 名,2026/11/26 10:32:18.456,否
1,（2）,第 1 組,Ava,"丁, 戊",第 2 名,2026/11/26 10:32:18.456,否
2,,,,無人作答,,,
3,,第 2 組,,'-5,第 1 名,2026/11/26 10:33:01.007,是
```

（第一個字元是 BOM，每列以 CRLF 結束。）

## 5. 檔名

- 下載檔名：`搶答結果_YYYYMMDD-HHmm.csv`，例如 `搶答結果_20261126-1032.csv`。
- ASCII 備用檔名：`results_YYYYMMDD-HHmm.csv`。
- 時間為 `QuizSession.openedAt`，以伺服器所在時區表示，月、日、時、分補零為兩位。

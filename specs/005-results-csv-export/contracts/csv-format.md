# CSV 檔案格式契約

**Feature**: `005-results-csv-export`

## 1. 編碼與結構

| 項目 | 規定 | 依據 |
|------|------|------|
| 字元編碼 | UTF-8，檔案開頭為 BOM（位元組 `EF BB BF`） | FR-011、research R4 |
| 換列 | CRLF（`\r\n`），最後一列之後也有 CRLF | RFC 4180 |
| 分隔字元 | 逗號 `,` | FR-012 |
| 欄數 | 每列固定 8 欄 | FR-005 |
| 第一列 | 表頭：`題號,子題,組別,送出者暱稱,答案,搶答順位,送出時間,是否搶答成功` | FR-005 |

## 2. 欄位值的編碼規則（依序套用）

0. **Excel 文字儲存格**優先判斷（見步驟 3 的說明，僅答案與暱稱欄）；不符合時再依序：
1. **公式防護**（FR-013）：值的第一個字元是 `=`、`+`、`-`、`@`、Tab（`\t`）或 CR（`\r`）時，在開頭加上 `'`。
2. **引號**（FR-012）：值含有 `,`、`"`、`\r`、`\n`，或開頭／結尾是空白時，整個值用 `"` 包住，值中的每個 `"` 寫成 `""`。
3. **Excel 文字儲存格**（FR-014，僅「答案」「送出者暱稱」欄）：值只含數字與 `+ - . , / : % $ e E`、空白且至少有一個數字，或是 `TRUE`／`FALSE`（不分大小寫）時，輸出 `="值"`（整格再套引號規則，即 `"=""值"""`），Excel 顯示值本身。這類值不再加 `'`（步驟 1 只處理其餘以 `=`、`+`、`-`、`@` 開頭的值）。
4. 其他值原樣輸出；空值（`null`）輸出空字串。

| 原始值 | 輸出 |
|--------|------|
| `甲` | `甲` |
| `蘋果, 香蕉` | `"蘋果, 香蕉"` |
| `他說"好"` | `"他說""好"""` |
| `第一行⏎第二行`（LF） | `"第一行⏎第二行"` |
| `=1+1` | `'=1+1` |
| `-5` | `"=""-5"""`（Excel 顯示 -5） |
| `007` | `"=""007"""`（Excel 顯示 007） |
| `1/2` | `"=""1/2"""`（Excel 顯示 1/2，不轉成日期） |
| `-abc` | `'-abc` |
| `=SUM(A1, B1)` | `"'=SUM(A1, B1)"` |
| ` 前後空白 ` | `" 前後空白 "` |
| `A,B`（暱稱） | `"A,B"` |
| `null` | （空） |

## 3. 列的內容與排序

欄位定義見 [data-model.md §2 ResultRow](../data-model.md)。排序：題號由小到大 → 同題依順位 → 同一筆題組送出依子題順序。

## 4. 範例

活動：第 1 題為 2 個子題的題組（子題欄為「子題1」「子題2」），第 2 題單題無人作答，第 3 題單題；
第 3 組 Milo 先送出第 1 題，第 1 組 Ava 接著送出；004 之前保存的第 2 組送出（沒有暱稱）送出第 3 題，答案含逗號。

```text
﻿題號,子題,組別,送出者暱稱,答案,搶答順位,送出時間,是否搶答成功
1,子題1,第 3 組,Milo,甲,第 1 名,2026-11-26 10:32:15,是
1,子題2,第 3 組,Milo,乙,第 1 名,2026-11-26 10:32:15,是
1,子題1,第 1 組,Ava,丙,第 2 名,2026-11-26 10:32:18,否
1,子題2,第 1 組,Ava,"丁, 戊",第 2 名,2026-11-26 10:32:18,否
2,,,,無人作答,,,
3,,第 2 組,,"=""-5""",第 1 名,2026-11-26 10:33:01,是
```

（第一個字元是 BOM，每列以 CRLF 結束。）

## 5. 檔名

- 下載檔名：`搶答結果_YYYYMMDD-HHmm.csv`，例如 `搶答結果_20261126-1032.csv`。
- ASCII 備用檔名：`results_YYYYMMDD-HHmm.csv`。
- 時間為 `QuizSession.openedAt`，以伺服器所在時區表示，月、日、時、分補零為兩位。

## 6. Excel 直接開啟的相容性（人工驗證後修正）

- **子題欄**：一律輸出「子題1」「子題2」…（N 為子題序號），不使用文件上的標記。「(1)」與全形「（1）」都會被 Excel 當成會計負數顯示為 `-1`；「1-1」會被轉成日期，所以也不用。
- **答案與暱稱**：Excel 會轉換的值（`007`→7、`1/2`→日期、`3:30`→時間、`1e5`→科學記號、`TRUE`→布林）改以 `="值"` 輸出，顯示原樣。
- **送出時間**：格式為 `YYYY-MM-DD HH:mm:ss`（例如 `2026-11-26 13:11:00`），不含毫秒。帶毫秒的 `YYYY/MM/DD HH:mm:ss.SSS` 會被 Excel 當成「分:秒.小數」而看不到日期與時；同一秒內的先後以「搶答順位」欄為準。
- 此時間格式只用於 CSV；Guided Notes 匯出（002 FR-018）維持原本帶毫秒的格式。
